# Hackathon submission preparation

Working title: **AsShown — Love the look. Know the details.**

AsShown helps shoppers evaluate clothing against practical must-haves, inspect the supporting listing evidence, and identify what is still unknown. Optional YouCam apparel previews remain separate from product suitability and appearance checks. A generated image never proves fit, fabric, or functional pockets.

## Significant changes from KeepMe

KeepMe baseline: `2c4053db1c5b3144be29340f57a5419824db4b96`. AsShown adds a consumer evidence/requirements workspace, variant-aware source records, seller clarification, three-item comparison, decision reports, profiles/account persistence, arrival review, moderated product contributions, language/speech assistance, support and a redesigned ivory/violet UI. The existing preview path was hardened for consent, task reservation, refresh recovery, deletion and repair lineage.
